🔌 方式3: API直接调用

适合需要自定义支付界面的开发者

代码示例:

// 第1步：登录获取JWT token const loginResponse = await fetch('http://47.109.140.124:8080/api/auth/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email: 'admin@example.com', password: 'admin123' }) }); const loginData = await loginResponse.json(); // 第2步：创建支付链接 const response = await fetch('http://47.109.140.124:8080/api/payment-links', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ' + loginData.token }, body: JSON.stringify({ title: 'API测试支付', amount: 15.50, description: '通过API创建的支付订单' }) }); const data = await response.json(); console.log('支付链接创建成功:', data);
