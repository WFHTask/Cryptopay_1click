⚙️ JavaScript动态加载

如果需要动态创建支付组件：

<div id="payment-container"></div>

<script>
// 从您的后端API获取支付订单信息
fetch('/api/payment/create', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        amount: 100,
        api_key: 'your_api_key'
    })
})
.then(response => response.json())
.then(data => {
    // 使用返回的 iframe_code
    document.getElementById('payment-container').innerHTML = data.data.iframe_code;
    
    // 或者使用 embed_url
    const iframe = document.createElement('iframe');
    iframe.src = data.data.embed_url;
    iframe.width = '450';
    iframe.height = '650';
    iframe.frameBorder = '0';
    iframe.scrolling = 'no';
    iframe.style.cssText = 'border: 2px solid rgba(0,255,159,0.3); border-radius: 12px;';
    document.getElementById('payment-container').appendChild(iframe);
});
</script>

💡 提示：
  • embed_url - 可直接在浏览器打开的嵌入式支付页面URL
  • iframe_code - 完整的iframe HTML代码，可直接使用
  • payment_url - 标准支付页面URL
