# 🎯 嵌入式支付页面使用指南

## 📝 功能说明

商户现在可以通过API直接获取一个可嵌入的支付页面URL，将其嵌入到自己的网站中，无需用户跳转！

## ✨ 特性

- ✅ **一键嵌入** - 使用iframe直接嵌入
- ✅ **Geek风格** - 保持霓虹绿色主题
- ✅ **二维码显示** - 自动生成支付二维码
- ✅ **倒计时** - 实时显示剩余时间
- ✅ **一键复制** - 复制金额和地址
- ✅ **响应式** - 自适应不同尺寸
- ✅ **无需跳转** - 直接在商户页面完成支付

## 🚀 快速使用

### 步骤1：创建支付订单

调用API创建支付订单：

```javascript
// JavaScript示例
const response = await fetch('http://localhost:8080/api/payment/create', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    api_key: 'YOUR_API_KEY',
    order_id: 'ORDER001',
    amount: 100.00,
    notify_url: 'https://your-domain.com/notify',
    redirect_url: 'https://your-domain.com/success'
  })
});

const data = await response.json();
console.log('嵌入URL:', data.data.embed_url);
console.log('iframe代码:', data.data.iframe_code);
```

API会返回：

### 步骤3：嵌入到您的网站

#### 方式1：直接使用iframe代码

```html
<!-- 直接粘贴返回的iframe_code -->
<iframe 
  src="http://localhost:3000/embed/payment/202510131760347925302225?..."
  width="450" 
  height="650" 
  frameborder="0" 
  scrolling="no"
  style="border: 2px solid rgba(0,255,159,0.3); border-radius: 12px;">

```

#### 方式2：动态创建iframe

```javascript
// JavaScript动态嵌入
const embedContainer = document.getElementById('payment-container');
embedContainer.innerHTML = data.data.iframe_code;
```

#### 方式3：使用embed_url直接跳转

```javascript
// 在新窗口打开
window.open(data.data.embed_url, '_blank', 'width=500,height=700');

// 或在当前窗口打开
window.location.href = data.data.embed_url;
```

### PHP集成示例

```php
<?php
// 创建支付订单
function createEmbedPayment($apiKey, $orderId, $amount) {
    $url = 'http://localhost:8080/api/payment/create';
    $data = [
        'api_key' => $apiKey,
        'order_id' => $orderId,
        'amount' => $amount,
        'notify_url' => 'https://your-domain.com/notify',
        'redirect_url' => 'https://your-domain.com/success'
    ];
    
    $ch = curl_init($url);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
    
    $response = curl_exec($ch);
    curl_close($ch);
    
    return json_decode($response, true);
}

// 使用示例
$result = createEmbedPayment('your_api_key', 'ORDER123', 100.00);

if ($result['success']) {
    // 方式1：直接输出iframe
    echo $result['data']['iframe_code'];
    
    // 方式2：自定义iframe
    $embedUrl = $result['data']['embed_url'];
    echo "<iframe src='$embedUrl' width='450' height='650' frameborder='0'></iframe>";
}
?>
```

```jsx
      <button onClick={handleBuy}>立即购买</button>
      
      {iframeCode && (
        <div dangerouslySetInnerHTML={{ __html: iframeCode }} />
      )}
    </div>
  );
}
```

## 🔒 安全注意事项

### 1. CORS配置
确保后端已配置CORS允许iframe嵌入：
```go
config.AllowOrigins = []string{"*"}  // 生产环境请限制具体域名
```

### 2. 内容安全策略
如果有CSP策略，需要允许iframe：
```html
<meta http-equiv="Content-Security-Policy" 
      content="frame-src http://localhost:3000;">
```

### 3. HTTPS要求
生产环境建议：
- ✅ 使用HTTPS
- ✅ 限制允许嵌入的域名
- ✅ 启用X-Frame-Options
